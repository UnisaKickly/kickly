# Modelli in formato testuale (docs/modelli)

Class diagram e sequence diagram in PlantUML (`class.puml`, `seq_<nome>.puml`),
versionati con il codice. Un agente legge un file di testo senza ambiguita',
un'immagine puo' essere letta male. Se il codice richiede di cambiare un modello,
la modifica va NELLA STESSA PR e va dichiarata nel template.
