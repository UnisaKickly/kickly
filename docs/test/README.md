# Category partition e test frame (docs/test)

Un file per caso d'uso: `cp_<UC>.md`, con parametri, categorie, scelte, vincoli
([error], [single]) e la tabella dei test frame TFxx con l'esito atteso preso dal
caso d'uso. I test frame sono decisi in progettazione, NON dedotti dal codice.
Nei test Dart il nome contiene l'id del frame (`tf10_dueAttive_rifiuta`).
